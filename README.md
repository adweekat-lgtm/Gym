# غول – Ghool

مدربك الشخصي — برنامج تمارين، تايمر وراحة، تقدّم، قياسات الجسم، الأكل، ومدرب ذكي.

## التثبيت على الجوال (PWA)
1. افتح رابط التطبيق (GitHub Pages) من الجوال.
2. **آيفون (Safari):** زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
3. **أندرويد (Chrome):** القائمة ⋮ ← "تثبيت التطبيق".

## للرجال وللبنات
عند التسجيل يختار المستخدم ذكر أو أنثى. للبنات: خطاب بصيغة المؤنث، برامج خاصة بالمرأة، وصور تمارين لمدرّبة بلبس محتشم.

## الصور
- صور تمارين الرجال من [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (ملكية عامة — Unlicense) في `img/ex/`.
- صور تمارين البنات مولّدة بالذكاء الاصطناعي في `img/exf/`، وتتفعّل من `FIMG` داخل `index.html`.
