# Dweekat Fitness

مدربك الشخصي — برنامج تمارين، تايمر وراحة، تقدّم، قياسات الجسم، الأكل، ومدرب ذكي.

## التثبيت على الجوال (PWA)
1. افتح رابط التطبيق (GitHub Pages) من الجوال.
2. **آيفون (Safari):** زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
3. **أندرويد (Chrome):** القائمة ⋮ ← "تثبيت التطبيق".
